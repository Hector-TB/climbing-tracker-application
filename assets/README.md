# Assets Directory

This directory contains app assets like icons and splash screens.

## Required Assets

When running the app, you'll need:
- `icon.png` - 1024x1024px app icon
- `splash.png` - 2048x2048px splash screen
- `adaptive-icon.png` - 1024x1024px Android adaptive icon
- `favicon.png` - 32x32px web favicon

## Creating Assets

You can create these using:
1. Design tools (Figma, Sketch, Adobe XD)
2. Online icon generators
3. Expo's asset generation tools

For now, the app will use default Expo assets if these are not present.
